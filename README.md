# Gros Mangeurs

Jeu débile : choisis une tête, mange les plus petites, fuis les plus grosses.
Souris sur ordi, joystick au doigt sur mobile.

## Déployer sur GitHub Pages

1. Crée un repo sur GitHub et pousse ce dossier (`index.html`, `game.js`, `img/`, `.nojekyll`).
2. Sur GitHub : Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le jeu est en ligne sur `https://<ton-pseudo>.github.io/<nom-du-repo>/`.

## Tester en local

```bash
python3 -m http.server 8000
```
puis ouvre http://localhost:8000
